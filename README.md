# 🧮 My Calculator

A sleek, modern calculator built with pure HTML, CSS, and JavaScript — no libraries or frameworks needed.

![Calculator Screenshot](screenshot.png)

## ✨ Features

- **Basic operations** — add, subtract, multiply, divide
- **Percentage** — quick percent conversion
- **Square root** — one-tap √
- **Power** — exponentiation (xʸ)
- **Sign toggle** — flip between ±
- **Backspace** — delete last character
- **Expression preview** — shows the last calculation
- **Keyboard support** — type numbers, operators, Enter to evaluate, Backspace/Delete to clear
- **Ripple effect** — smooth click feedback on every button
- **Responsive** — works on mobile and desktop

## 🎨 Design

Dark glassmorphism theme with:
- Frosted glass card with gradient border glow
- Animated star particles background
- Purple-to-pink gradient accents
- Smooth hover and press animations

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Enter numbers |
| `.` | Decimal point |
| `+ - * /` | Operators |
| `%` | Percentage |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last char |
| `Escape` or `Delete` | Clear all |
